# Database

PostgreSQL 16. Schema managed by **Alembic**; `alembic upgrade head` is the only
sanctioned way to change a live schema.

## Conventions

- Surrogate primary keys: UUID v4 (`uuid` type).
- Every table has `created_at` / `updated_at` (timezone-aware, UTC).
- Per-user data carries `user_id` FK with `ON DELETE CASCADE`.
- Money-like precision uses `Numeric`; nutrition amounts use `Float` with fixed
  rounding applied in `calculations/`, never ad hoc in queries.
- Indexes on every FK and on hot filters (`logged_on`, `user_id + logged_on`).

## Core entities

### Identity
| Table | Purpose |
|-------|---------|
| `users` | Account, email, hashed password, role |
| `profiles` | Display name, sex, birth date, height, units |
| `body_metrics` | Dated weight, body-fat %, measurements |
| `goals` | Target weight, macro split, step goal, training goal |

### Nutrition
| Table | Purpose |
|-------|---------|
| `foods` | Food database: name, brand, per-100 g macros + micros |
| `food_servings` | Named servings for a food (e.g. "1 cup" = 240 g) |
| `meals` | A logged eating event (user, timestamp, meal type) |
| `meal_items` | Food + quantity within a meal |
| `favorites` | User's saved foods |
| `hydration_logs` | Water intake entries |

### Training
| Table | Purpose |
|-------|---------|
| `exercises` | Library: name, muscle group, equipment, instructions |
| `programs` | Named training program (user-owned or template) |
| `program_days` | A day within a program, ordered |
| `program_exercises` | Exercise slot with target sets/reps |
| `workout_sessions` | A performed session (date, duration, notes, RPE) |
| `workout_sets` | Set within a session: exercise, weight, reps, RPE |
| `personal_records` | Best effort per exercise (weight/reps/1RM estimate) |

### Recovery & Activity
| Table | Purpose |
|-------|---------|
| `sleep_logs` | Bed/wake time, duration, quality, resting HR, HRV |
| `soreness_logs` | Per-muscle soreness ratings |
| `step_logs` | Daily step count and active minutes |

## Relationships (selected)

```
users 1─* meals 1─* meal_items *─1 foods 1─* food_servings
users 1─* workout_sessions 1─* workout_sets *─1 exercises
users 1─* programs 1─* program_days 1─* program_exercises
users 1─* sleep_logs
users 1─* step_logs
```

## Migrations

```bash
alembic revision --autogenerate -m "add x"
alembic upgrade head
alembic downgrade -1
```

Always review autogenerated migrations; autogenerate misses server-side
defaults and index changes.
